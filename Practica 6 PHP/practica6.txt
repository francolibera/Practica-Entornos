Ejercicio 1

Para comenzar la comunicación con un servidor de base de datos MySQL, es
necesario abrir una conexión a ese servidor. 
Para inicializar esta conexión, PHP ofrece la función: mysqli_connect($hostname ,
$nombreUsuario , $contraseña)

Todos sus parámetros son opcionales, pero hay tres de ellos que generalmente son necesarios: 
hostname, contraseña y nombreUsuario

Una vez abierta la conexión, se debe seleccionar una base de datos para su uso, mediante la función:
mysqli_select($nombreConexión,
$nombreBaseDatos)

Esta función debe pasar como parámetro:

nombreBaseDatos y nombreConexión

La función mysqli_query () se utiliza para:

Ejecutar consultas en la base de datos

y requiere como parámetros:

nombreConexión y la query (la propia consulta en el lenguaje de la base de datos)

La cláusula or die() se utiliza para:

Capturar el error

y la función mysqli_error () se puede usar para:

Devuelve el último mensaje de error para la llamada más
reciente a una función de MySQLi que puede haberse
ejecutado correctamente o haber fallado.
