Ejercitación 1

1. HTML (HyperText Markup Language): Es el lenguaje de marcado estándar para crear páginas web, creado por Tim Berners-Lee (1991). Versiones principales: HTML 2.0, HTML 3.2, HTML 4.01, XHTML, y la actual HTML5.

2. Principios del W3C: Separación de estructura (HTML) y presentación (CSS), uso de marcado semántico, diseño accesible para todos los usuarios y dispositivos.

3. Desaprobado (Deprecated): Se desaconseja su uso porque hay alternativas mejores (generalmente CSS), pero los navegadores aún deben soportarlo por compatibilidad. Obsoleto (Obsolete): Ya no forma parte del estándar oficial y los navegadores no tienen obligación de renderizarlo.

4. DTD (Document Type Definition): Define las reglas y elementos permitidos en el documento HTML. En HTML 4.01 existen tres: Strict (Estricto, sin tags desaprobados), Transitional (Transicional, permite tags de diseño antiguos) y Frameset (Para uso con marcos/frames).

5. Metadatos: Es información sobre el documento (autor, codificación, descripción, palabras clave) que no se muestra directamente en la página. Se especifican usando la etiqueta <meta> dentro de la sección <head>.

Ejercitación 2

2.a) Comentario HTML. Va en cualquier parte. No produce efecto visual.
2.b) Elemento de bloque <div>. Va en el <body>. Define una división genérica. Atributo: id="bloquel" (opcional).
2.c) Elemento vacío <img>. Va en <body>. Muestra una imagen. Atributos obligatorios: src (ruta) y alt (texto alternativo). Opcionales: id, name, width, height, longdesc.
2.d) Elementos <meta>. Van en el <head>. El primero define palabras clave (keywords) para buscadores. El segundo define la fecha de expiración del caché. Atributos: name, lang, content, http-equiv. Ninguno es obligatorio por sí solo, pero content lo es si se usa name o http-equiv.
2.e) Elemento <a> (Ancla/Enlace). Va en el <body>. Crea un hipervínculo. Atributos: href (obligatorio para enlazar), type, hreflang, charset, rel (todos opcionales, aportan info semántica).
2.f) Elemento <table>. Va en el <body>. Crea una tabla. Tiene título <caption>, filas <tr>, y encabezados de tabla <th>. Atributos: width, summary, align, scope.

Ejercitación 3

3.a) Enlaces: El 1ro es normal. El 2do abre en nueva pestaña (target="_blank"). El 3ro tiene metadatos MIME. El 4to va al inicio de la página actual (#). El 5to va a un ancla interna llamada "arriba". El 6to define dicha ancla.
3.b) Imágenes y enlaces: 1) Imagen seguida de texto enlace. 2) La imagen ES el enlace. 3) La imagen y el texto forman un único enlace. 4) La imagen es un enlace y el texto es otro enlace separado.
3.c) Listas: 1) Lista desordenada (viñetas). 2) Lista ordenada (números). 3) Lista ordenada donde el 2do ítem fuerza el valor 2. 4) Falsa lista creada con texto y saltos de línea <br> dentro de un bloque de cita.
3.d) Tablas: La 1ra usa la semántica estándar (<th> para encabezados que ya centran y ponen negrita). La 2da simula encabezados usando <td> con <div> y <strong>.
3.e) colspan: La 2da tabla usa colspan="3" para que una celda ocupe el ancho de 3 columnas. La 1ra no lo hace bien.
3.f) rowspan vs colspan: La 1ra usa rowspan="2" (une dos celdas verticalmente/filas). La 2da usa colspan="2" (une dos celdas horizontalmente/columnas).
3.g) Márgenes de tabla: La 2da anula el espacio entre celdas y su contenido con cellpadding="0" y cellspacing="0".
3.h) Formularios: 1) Usa método POST. 2) Usa método GET. 3) Usa acción mailto y botón reset.
3.i) Botones: <button> permite incluir HTML complejo en su interior (como una imagen + texto). <input type="button"> solo acepta texto simple en su atributo value.
3.j) Radio buttons: En el 1ro, ambos comparten el mismo name="opcion", por lo que solo se puede elegir uno (excluyentes). En el 2do tienen distinto name, permitiendo seleccionar ambos a la vez (funcionan como checkboxes, lo cual es incorrecto para radios).
3.k) Select: El 1ro es un menú desplegable normal de selección única. El 2do (multiple="multiple") muestra una lista abierta y permite seleccionar varios elementos con la tecla Ctrl/Shift.
